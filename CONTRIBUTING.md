# Contributing and mathematical review

This repository is primarily a public research record and source release. Mathematical criticism, corrections, and independent reconstructions are welcome.

## Reporting a mathematical defect

Please identify the **earliest exact point of failure** you can locate. Useful reports include:

- a false identity or algebraic expansion;
- an invalid inequality or incorrect exponent;
- a hypothesis mismatch;
- a density-definition mismatch;
- a gluing/separation condition that cannot be satisfied as stated;
- a sign-pattern or summability failure;
- a Descartes-counting defect;
- an invalid Rouché/Hurwitz limiting step;
- a numerical constant that does not reproduce.

Please include enough detail for the objection to be independently checked. A short explicit countercalculation is preferable to a general assessment.

## Corrections

For minor typographical fixes, a pull request is welcome. For substantive mathematical changes, please open an issue first so that the claim boundary and version history remain explicit.

## Scope boundary

The public v2.0 release does not include private correspondence, internal chat history, internal handovers, or protected parallel research. Please do not submit such material to this repository.

## Verification status

See [`verification/VERIFICATION_STATUS.md`](verification/VERIFICATION_STATUS.md). Acceptance of an issue or pull request does not by itself constitute peer review or formal certification.
