## Purpose

v2.0 converts the restricted August 2026 preservation state into one canonical public preprint and reproducible source package.

## Main changes from restricted v1.0

- Replaces the three-development-PDF presentation with one canonical manuscript.
- Integrates the referee-hardened lower-density proof details into the combined failure-and-repair paper.
- Adds a reader map explaining the three mechanisms: macroscopic redistribution, amplitude compression, and amplitude-sensitive repair.
- Makes the geometric role of the odd zero lattice explicit without using private correspondence as a source or artifact.
- Retains the stronger \(\ell^1\) upper-density construction.
- Retains the Central Gaussian Dominance theorem and quantitative corollaries.
- Removes the exploratory \(h\downarrow1\) sharpening from the public claim set.
- Replaces the earlier cross-density status language with the narrower statement that cross-direction inequalities are not addressed in this release.
- Excludes private correspondence, chat transcripts, internal handovers, and protected parallel research.
- Adds explicit claim-boundary, verification-status, citation, licensing, and hash files.
